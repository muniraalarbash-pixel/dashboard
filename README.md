# داش بورد · Dashboard

**Upload. Automate. Analyze.**

منصة ويب تحوّل ملف Excel إلى داش بورد تفاعلي بهوية الجهة البصرية، وتشاركه برابط للعرض فقط.

**[جرّب العرض التجريبي](https://muniraalarbash-pixel.github.io/dashboard/view.html?demo=1)**

## المميزات
- **رفع Excel أو CSV أو لصق جدول:** يتعرف تلقائيًا على أنواع الأعمدة (تاريخ، رقم، فئة)، ويفهم الأرقام العربية و«ر.س»، ويحذف صفوف الإجمالي حتى لا يتكرر الجمع.
- **المستهدف مقابل الفعلي:** ارفع ملف المستهدف ويحسب نسبة الإنجاز لكل فرع أو قسم.
- **الهوية البصرية:** ارفع الشعار وتُستخرج ألوانه تلقائيًا، واختر الخط.
- **ثلاثة قوالب:** مربعات تحليلية، تقرير تنفيذي، ملخص للجوال.
- **سجل تحديثات:** كل رفع يُحفظ كإصدار، والمؤشرات تقارن بالفترة السابقة.
- **مشاركة آمنة:** رابط للعرض فقط، مع كلمة مرور اختيارية. الزائر يفلتر ويبحث ويرتب ولا يعدل.
- **تحديث تلقائي:** صفحة العرض تلتقط البيانات الجديدة كل دقيقتين دون إعادة تحميل.
- **حسابات متعددة:** كل مستخدم يرى مشاريعه فقط (Row Level Security).

## التقنيات
HTML · CSS · JavaScript (ES Modules) · Chart.js · SheetJS · Supabase (Auth, Postgres, Storage, RLS) · GitHub Pages

## التشغيل
1. أنشئ مشروعًا في [Supabase](https://supabase.com) وشغّل الملف `supabase/schema.sql` من **SQL Editor**.
2. ضع `Project URL` و`anon public key` في `assets/js/config.js`.
3. فعّل **GitHub Pages** من إعدادات المستودع (Branch: `main`، المجلد: `/root`).

## هيكل المشروع
```
index.html      الصفحة الرئيسية وتسجيل الدخول
app.html        مشاريعي
project.html    تحرير المشروع: التفاصيل، الهوية، البيانات، القالب، المشاركة
view.html       صفحة العرض العامة (والعرض التجريبي ?demo=1)
assets/js/parse.js    قراءة وتنظيف ملفات Excel
assets/js/engine.js   النموذج والتجميع والمؤشرات والهوية
assets/js/render.js   القوالب والرسوم
supabase/schema.sql   الجداول والصلاحيات ودالة المشاركة
```
