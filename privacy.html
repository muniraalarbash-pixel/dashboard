ما هي «لوحة التحكم»؟

«لوحة التحكم» أداة ويب مجانية تحوّل ملفات Excel إلى لوحات بيانات تفاعلية يمكن مشاركتها برابط للعرض فقط. الموقع مشروع شخصي في تحليل البيانات من تصميم وتطوير منيرة الأربش، ويُقدَّم كما هو دون ضمانات.

البيانات التي نحفظها

  • بيانات الحساب: البريد الإلكتروني، وكلمة المرور محفوظة مشفّرة (لا يمكن لأحد قراءتها)، والاسم إذا أضفته.
  • بيانات المشاريع: العنوان والوصف والهوية البصرية والقالب، والجدول المستخرج من ملفك. ملف Excel نفسه لا يُرفع؛ يُقرأ داخل متصفحك ويُحفظ الجدول الناتج فقط.
  • الشعارات: الصور التي ترفعها كشعار تُحفظ في مساحة تخزين عامة، أي أن من يملك رابط الصورة يستطيع فتحها.
  • سجل التحديثات: كل رفع يُحفظ كنسخة مع تاريخه لعرض المقارنة بالفترة السابقة.
  • مشاهدات الرابط: عدد مرات فتح الرابط المنشور يوميًا، بدون تسجيل من فتحه.

من يستطيع رؤية بياناتك

  • أنت فقط، داخل حسابك. قاعدة البيانات تفرض ذلك بصلاحيات على مستوى كل صف (Row Level Security).
  • إذا فعّلت «النشر»، يستطيع أي شخص لديه الرابط مشاهدة آخر نسخة من لوحة التحكم دون تعديل. يمكنك إضافة كلمة مرور للرابط أو إيقاف النشر في أي وقت.
  • لا نبيع البيانات ولا نشاركها مع أي جهة لأغراض تسويقية.

أين تُحفظ البيانات

  • قاعدة البيانات والحسابات والتخزين: خدمة Supabase، على خوادم في طوكيو (اليابان).
  • صفحات الموقع: GitHub Pages.
  • الخطوط والمكتبات: تُحمَّل من Google Fonts وjsDelivr وcdnjs، وهذه الخدمات قد ترى عنوان IP الخاص بجهازك كأي موقع.

إذا كانت بياناتك خاضعة لاشتراطات استضافة داخل المملكة (مثل نظام حماية البيانات الشخصية)، ننصح بعدم رفع بيانات شخصية أو حساسة، واستخدام بيانات مجمّعة أو مموّهة.

التخزين في المتصفح

نستخدم التخزين المحلي في متصفحك لحفظ جلسة الدخول ولون الموقع واللغة التي اخترتها فقط. لا نستخدم ملفات تعريف ارتباط للإعلانات أو التتبّع.

حذف بياناتك

  • تستطيع حذف أي مشروع وكل نسخه من صفحة المشروع ← «المشاركة» ← «حذف المشروع».
  • لحذف الحساب بالكامل، تواصل معنا عبر صفحة المشروع على GitHub.

What is Dashboard?

Dashboard is a free web tool that turns Excel files into interactive dashboards you can share through a view-only link. It is a personal data-analysis project designed and built by Munirah Alarbash, provided as is, without warranties.

Data we store

  • Account: your email, your password stored hashed (nobody can read it), and your name if you add one.
  • Projects: title, description, visual identity, template, and the table extracted from your file. The Excel file itself is never uploaded; it is read in your browser and only the resulting table is saved.
  • Logos: images you upload as a logo are kept in public storage, so anyone with the image link can open it.
  • Update history: each upload is saved as a version with its date, to compare with the previous period.
  • Link views: a count of how many times a published link was opened, per day. We don’t record who opened it.

Who can see your data

  • Only you, inside your account. The database enforces this with row-level security.
  • If you turn on “Publish”, anyone with the link can view the latest version without editing. You can add a password or turn publishing off at any time.
  • We don’t sell data or share it with anyone for marketing.

Where data is stored

  • Database, accounts and storage: Supabase, on servers in Tokyo, Japan.
  • Website pages: GitHub Pages.
  • Fonts and libraries: loaded from Google Fonts, jsDelivr and cdnjs, which may see your device’s IP address like any website.

If your data must be hosted inside Saudi Arabia (for example under the Personal Data Protection Law), avoid uploading personal or sensitive data and use aggregated or anonymized figures instead.

Browser storage

We use your browser’s local storage only for your sign-in session, your chosen site color and language. We don’t use advertising or tracking cookies.

Deleting your data

  • Delete any project and all its versions from the project page → “Sharing” → “Delete project”.
  • To delete your whole account, contact us through the project page on GitHub.

Changes to this policy

We may update this page when new features are added; the date at the top shows the latest update.
